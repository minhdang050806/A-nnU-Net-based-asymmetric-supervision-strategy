# Paper source

LaTeX source and figures for the LISA 2026 Task 2 challenge report.

## Build

Springer LNCS class, `splncs04` bibliography style. Both are vendored here, so
no additional CTAN packages are needed beyond a standard TeX Live install.

```bash
cd paper
pdflatex paper && bibtex paper && pdflatex paper && pdflatex paper
```

or, more simply:

```bash
latexmk -pdf paper.tex
```

## Figures

| Figure | Source | Output |
| :-- | :-- | :-- |
| 1 — HF/LF annotation disagreement | `../scripts/figures/make_dataset_figure.py` | `figures/dataset_hf_lf_disagreement.{pdf,png}` |
| 2 — OS50 + AURA framework | hand-authored in diagrams.net | `figures/framework_os50_aura.{pdf,png}` |
| 3 — Qualitative comparison | `../scripts/figures/make_qualitative_figure.py` | `figures/qualitative_os50_aura.{pdf,png}` |

Figures 1 and 3 are regenerated by their scripts and need the challenge data —
and, for Figure 3, model predictions. See
[`../docs/REPRODUCE.md`](../docs/REPRODUCE.md) §10. The cases they show are
fixed by pre-specified quantitative selection rules rather than chosen
visually; each script's module docstring states the rule.

**Figure 2 is a hand-drawn diagram, not generated code.** The editable
diagrams.net source is embedded in the PDF itself, so
`figures/framework_os50_aura.pdf` can be reopened and edited directly at
[app.diagrams.net](https://app.diagrams.net) (File → Open From → Device). After
editing, re-export the PDF and regenerate the README's PNG at matching
resolution:

```bash
python -c "
import fitz
d = fitz.open('figures/framework_os50_aura.pdf')
d[0].get_pixmap(matrix=fitz.Matrix(300/72, 300/72), alpha=False).save('figures/framework_os50_aura.png')"
```

An earlier matplotlib draft of the same diagram is kept for provenance at
[`../scripts/figures/make_framework_figure.py`](../scripts/figures/make_framework_figure.py).
It is superseded, writes to a different filename, and is not part of
reproducing the paper.

Figure 4 is plotted from the official LISA 2026 leaderboard export. That export
is challenge-owned data and is not redistributed here, so only the rendered PDF
is included.

## Anonymization

`paper.tex` carries a `\blindreview` switch. Uncommenting `\blindreviewtrue`
near the top replaces the author block with an anonymous one for double-blind
submission. It is off in the committed source.

## Blind-review note

This repository is named and attributed. If the manuscript is under
double-blind review at any venue, do not link this repository from the
submitted PDF.
